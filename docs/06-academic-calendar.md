## Pre-work (Weeks −4 to 0, self-paced, 40 h)

Python basics (variables, control flow, functions, lists and dictionaries, files), Jupyter and VS Code, Excel for finance (returns, NPV/IRR, charts), algebra, probability and statistics refresher, and a primer on how stock markets work. **Entry assessment** in Week 0: Python and quantitative basics, with a pass mark of 60% and one retake.
